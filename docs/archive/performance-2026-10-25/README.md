# Archived performance reports

These reports are retained as historical evidence, but are no longer the primary
results. Their measurements use older software revisions, earlier bridge builds,
or a narrower experiment than the current comparison.

Use the current [performance summary](../../performance/PERFORMANCE_SUMMARY.md) first. It
contains the master table for the optimized two-PC and real-phone direct/relay
runs. Raw ignored artifacts remain under the original `artifacts/` directories.

The archived files are:

- `DUAL_PC_CELLULAR_VIDEO.md`: pre-summary two-PC comparison and its old window diagnosis.
- `REAL_NETWORK_VIDEO.md`: earlier physical phone runs and injected-failure run.
- `REVERSE_CELLULAR_VIDEO.md`, `REVERSE_CELLULAR_DIRECT_VIDEO.md`: earlier reverse-direction bridge runs.
- `BRIDGE_PERFORMANCE.md`: bridge stress tests and old no-bridge controls.
- `CELLULAR_DIRECTION_REPEAT.md`, `NATIVE_CELLULAR_FORWARD_REPEAT.md`: earlier sequential direction controls.

They should not be mixed numerically with the master table without checking their
client revision, bridge mode, path, and measurement definition.
